# VitePress站点重构

这个目录用于沉淀当前仓库从原始 Markdown 资料库，重构为可运行、可导航、可持续维护的 VitePress 知识站点的过程文档。

优先从下面几个入口开始：

- [里程碑规划](./docs/00-里程碑规划.md)
- [M1任务拆解：首页与模块导航增强](./docs/01-M1任务拆解-首页与模块导航增强.md)
- [M1详细设计：首页信息架构与模块总览](./docs/02-M1详细设计-首页信息架构与模块总览.md)
- [开发记录：VitePress知识库首页与导航增强](./docs/03-开发记录-VitePress知识库首页与导航增强.md)

## 当前目标

这轮重构不只是把 Markdown 跑起来，而是要逐步形成一套稳定的文档站交付流：

- 有可持续同步的站点生成脚本
- 有按模块组织的内容导航
- 有适合长期阅读的首页与模块入口
- 有过程文档、设计文档和开发记录

## 当前范围

当前范围主要覆盖：

- VitePress 站点底座
- Markdown 镜像同步与构建兼容层
- 首页与模块导航增强
- 后续里程碑规划与持续迭代
