# 里程碑规划

这份里程碑规划文档，用来定义当前仓库 VitePress 站点重构项目的执行顺序、交付物和当前状态。

## 项目目标

把当前仓库中大量分散的 Markdown 资料，逐步整理成一个具备下面这些特征的知识站点：

- 能自动接入新增 Markdown 内容
- 能按模块、目录和重点专题清晰导航
- 能在历史资料脏数据存在的前提下稳定构建
- 能持续演进首页、模块入口、搜索与阅读体验
- 有完整的过程文档与交付记录

## 里程碑总览

### M0：站点底座落地

目标：先把仓库资料重构成可以实际跑通的 VitePress 站点。

交付物：

- `package.json`
- `scripts/generate-vitepress.mjs`
- 自动生成的 `docs-site` 站点镜像能力
- 可运行的 `npm run dev` / `npm run build` / `npm run preview`

当前状态：已完成。

### M1：首页与模块导航增强

目标：在站点可跑通的基础上，补齐首页信息架构、模块推荐区、模块总览页和更适合阅读的导航展示。

交付物：

- 首页增强版
- 模块总览增强版
- 对应任务拆解文档
- 对应详细设计文档
- 对应开发记录文档

当前状态：进行中。

### M2：专题入口与推荐阅读增强

目标：从“按目录浏览”继续走向“按主题浏览”，为高价值内容补齐专题入口与推荐阅读链路。

候选方向：

- Vue / Nuxt 专题入口
- 面试整理专题入口
- 构建与工程化专题入口
- AI 学习专题入口

当前状态：待开始。

### M3：站点体验与发布能力增强

目标：继续补齐搜索、SEO、构建性能与部署能力，让站点更接近正式可发布状态。

候选方向：

- 搜索体验优化
- 构建告警治理
- 发布脚本或 CI
- 站点元信息和社交分享优化

当前状态：待开始。

## 当前推荐执行顺序

建议按下面顺序持续推进：

- 先有里程碑规划
- 再有某一轮任务拆解
- 再补详细设计
- 再做功能开发与自测
- 最后补开发记录 / 技术博客并提交推送

## 当前阶段

当前阶段：M0 已完成 + M1 首页与模块导航增强进行中。

## 当前完成标准

判断当前某一轮是否真正完成，可以看下面这些条件是否都满足：

- 对应功能已经落地
- `npm run build` 已通过
- 关键页面预览访问已通过
- 对应任务拆解文档已完成
- 对应详细设计文档已完成
- 对应开发记录文档已完成
- Git 提交与推送已完成
