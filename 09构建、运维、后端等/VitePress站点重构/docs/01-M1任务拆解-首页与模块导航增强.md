# M1任务拆解：首页与模块导航增强

这份文档用于定义 `M1` 的具体任务拆解。本轮目标是在 `M0` 站点底座可运行之后，补齐首页信息架构与模块导航体验。

## 本轮目标

让当前 VitePress 站点从“已经能展示全部 Markdown”继续升级到“首页可快速理解、模块入口更明确、重点内容更容易进入”的状态。

## 本轮对象

本轮主要围绕下面这些内容推进：

- `scripts/generate-vitepress.mjs`
- 自动生成首页
- 自动生成 `内容导航/` 总览页
- 自动生成模块总览页
- VitePress 主题配置与站点信息表达

## 拆解顺序

### 任务一：梳理首页信息架构

明确首页应该表达什么：

- 这个站点是什么
- 当前一共有多少模块与多少文档
- 哪些模块值得优先进入
- 哪些专题适合作为重点入口

### 任务二：梳理模块导航展示

明确内容导航页与模块总览页应该表达什么：

- 模块数量与文档规模
- 模块推荐入口
- 模块间的优先级
- 从总览到具体模块的进入路径

### 任务三：功能开发

在生成脚本中实现：

- 首页增强
- 模块总览增强
- 更清晰的导航与统计信息

### 任务四：自测验证

至少完成这些检查：

- `npm run docs:sync` 通过
- `npm run build` 通过
- 首页预览访问通过
- 内容导航页预览访问通过

### 任务五：记录与沉淀

补齐：

- 开发记录 / 技术博客
- Git 提交与推送

## 本轮完成标准

本轮完成时，应满足：

- 首页已经从简单入口升级成结构化首页
- 内容导航页和模块总览页更适合浏览
- 自测通过
- 已完成开发记录沉淀
