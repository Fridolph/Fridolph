# M2任务拆解：专题入口与推荐阅读增强

这份文档用于定义 `M2` 的具体任务拆解。本轮目标是在 `M1` 首页与模块导航增强之后，继续补齐专题入口与推荐阅读链路。

## 本轮目标

让当前站点从“按模块浏览”继续升级到“按主题进入”，使用户可以更快地从首页或专题页进入高价值内容集合。

## 本轮对象

本轮主要围绕下面这些内容推进：

- 首页专题推荐区
- 专题导航页
- 专题详情页
- 模块内推荐阅读聚合逻辑
- 生成脚本中的专题配置与自动产出能力

## 拆解顺序

### 任务一：定义专题集合

明确哪些模块适合先形成专题入口：

- Vue / Nuxt
- 面试整理
- 构建与工程化
- AI 学习

### 任务二：设计推荐阅读策略

明确推荐阅读从哪里来：

- 模块内优先入口
- 模块内高价值文档
- 模块级总览与方法文档
- 首页与专题页之间的联动关系

### 任务三：功能开发

在生成脚本中实现：

- 首页专题推荐区
- `专题导航/` 总览页
- 各专题独立入口页
- 导航栏专题入口接入

### 任务四：自测验证

至少完成这些检查：

- `npm run docs:sync` 通过
- `npm run build` 通过
- 首页预览访问通过
- `专题导航/` 预览访问通过
- 至少一个专题详情页预览访问通过

### 任务五：记录与沉淀

补齐：

- 开发记录 / 技术博客
- Git 提交与推送

## 本轮完成标准

本轮完成时，应满足：

- 站点已支持从首页进入专题推荐区
- 已生成专题导航总览页与专题详情页
- 推荐阅读链路已形成
- 自测通过
- 已完成开发记录沉淀
