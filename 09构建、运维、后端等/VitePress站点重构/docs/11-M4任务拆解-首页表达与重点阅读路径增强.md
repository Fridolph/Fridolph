# M4 任务拆解：首页表达与重点阅读路径增强

这份任务拆解文档用于承接 VitePress 站点重构的下一阶段工作：在 M3 已完成“可发布”基础上，继续提升站点的首页表达、阅读入口和内容导览效率。

## 本轮目标

让站点不只是“有内容、有搜索、能发布”，还要能更清楚地回答下面几个问题：

- 这个站点里有什么
- 新读者应该先从哪里开始
- 最近哪些内容有更新
- 某个专题推荐按什么顺序阅读

## 本轮交付范围

本轮优先交付下面四类能力：

- 首页信息展示增强
- 最近更新入口
- 学习路径与阅读建议增强
- 模块页 / 专题页的卡片化展示增强

## 任务拆解

### 任务一：首页信息架构升级

目标：让首页同时具备站点统计、重点入口、专题入口和最近更新四类信息。

子任务：

- 为首页新增站点统计卡片
- 为首页新增重点模块卡片区
- 为首页新增专题卡片区
- 为首页新增最近更新区
- 调整首页文案，让“搜索、发布、阅读路径”表达更完整

预期结果：

- 首页更像知识站入口，而不是简单索引页
- 新读者进入后可快速理解站点结构与重点内容

### 任务二：重点阅读路径增强

目标：把“专题存在”升级成“专题有建议阅读顺序”。

子任务：

- 基于现有专题模块生成阅读路径
- 在首页增加建议阅读路径区
- 在专题详情页展示分步骤阅读入口

预期结果：

- 专题页不只展示链接集合，而是开始具备策展能力
- 阅读顺序更明确，适合首次进入该主题的读者

### 任务三：模块页与专题页展示增强

目标：把原有的大段列表增强为更易扫读的卡片化入口。

子任务：

- 为模块推荐入口增加卡片展示
- 为模块页增加最近更新区
- 为专题页增加覆盖模块卡片与推荐阅读卡片
- 保留原有文档列表作为兜底完整索引

预期结果：

- 总览页更容易扫读
- 模块页与专题页更适合快速点击进入

### 任务四：自定义主题组件接入

目标：在不放弃自动生成策略的前提下，用少量可复用 Vue 组件提升展示质量。

子任务：

- 设计并接入站点统计卡片组件
- 设计并接入通用数据卡片组件
- 设计并接入阅读路径组件
- 将组件统一挂载到 VitePress 自定义主题中

预期结果：

- 继续保持生成优先
- 通过少量主题组件增强首页和导航页表现力

## 本轮执行顺序

仍然按照当前项目约定推进：

1. 先完成任务拆解
2. 再补详细设计
3. 再进入开发实现
4. 开发完成后执行自测
5. 自测通过后补开发记录与技术博客
6. 最后执行 Git 提交与推送

## 风险与注意事项

- 自定义主题组件必须保持轻量，避免把生成站点改成高度手工维护模式
- 组件需兼容 VitePress Markdown 页面中的直接引用
- “最近更新”应基于原始 Markdown 文件时间，而不是生成文件时间
