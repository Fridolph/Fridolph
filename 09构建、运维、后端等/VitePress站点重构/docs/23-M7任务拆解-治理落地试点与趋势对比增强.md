# M7 任务拆解：治理落地试点与趋势对比增强

这份任务拆解文档用于承接 M7：在 M6 已经具备治理热点、质量基线和回归校验的基础上，继续推进一次真实的内容治理落地试点，并把治理结果以趋势形式展示出来。

## 本轮目标

让治理不只是“报告问题”和“阻止回归”，还要真正完成一轮可复用的修复实践。

## 本轮交付范围

- 缺少一级标题自动修复脚本
- `07四艺` 模块治理试点
- 站点治理页趋势信息增强
- 更新后的质量基线

## 任务拆解

### 任务一：自动修复脚本

目标：为缺少一级标题问题建立一个可复用的修复工具。

子任务：

- 新增缺少一级标题修复脚本
- 支持按目录批量处理 Markdown
- 自动为 `index.md` 使用目录名作为标题
- 自动跳过已有一级标题的文档

### 任务二：治理试点落地

目标：选一个治理热点中体量可控的模块，完成真实修复。

子任务：

- 选择 `07四艺` 作为试点模块
- 批量补齐缺少一级标题文档
- 重新生成质量报告并观察指标变化

### 任务三：趋势对比增强

目标：让治理页能看出当前结果相对基线是变好、持平还是回退。

子任务：

- 在治理页增加质量趋势区
- 在概览卡片中展示相对基线变化
- 保持治理热点模块与路径展示不变

### 任务四：基线更新

目标：把试点治理后的更优结果回写成新的质量基线。

子任务：

- 重新计算治理后指标
- 更新 `docs-quality-baseline.json`
- 确保 `docs:check` 以后基于新基线守门
