# 开发记录：VitePress 缺少一级标题治理试点与趋势增强

## 背景

M6 已经把治理推进到“能看见问题、能排序优先级、能阻止回归”的阶段，但治理如果一直停留在报表层，就还差最后一段：真实修复。

所以 M7 的重点，是做一次可复用的治理落地试点。

## 本轮改动

### 1. 新增缺少一级标题修复脚本

新增 `scripts/fix-missing-h1.mjs`，支持按目录批量补齐缺少一级标题的 Markdown 文档。

### 2. 选 `07四艺` 做试点模块

本轮选择 `07四艺` 作为试点，一次性补齐了 35 个缺少一级标题的文档。

### 3. 治理页增加趋势表达

治理页新增了相对基线的变化信息，开始可以直接看出某类问题是下降、持平还是回退。

### 4. 更新质量基线

在试点修复稳定通过后，把新的更优指标回写到基线文件，后续 `docs:check` 将基于更严格的新基线守门。

## 本轮价值

M7 的价值不在于一次性清理完所有问题，而在于证明：

- 治理可以通过脚本批量落地
- 治理结果可以被趋势视图直接感知
- 更优结果可以回写成新的守门基线
