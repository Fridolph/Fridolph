# M8 任务拆解：治理扩面与模块修复清单增强

这份任务拆解文档用于承接 M8：在 M7 已经完成 `07四艺` 缺少一级标题治理试点后，继续把这套方法扩面到更多可控模块，并把治理页补成可行动的修复清单视图。

## 本轮目标

让治理从“单模块试点”走向“多模块扩面”，并让治理页能直接告诉维护者：

- 这轮已经修了哪些模块
- 下一批最值得修哪些模块

## 本轮交付范围

- `04非典型工具、类库等` 标题治理扩面
- `10其他` 标题治理扩面
- 治理页“本轮已治理模块 / 下一批推荐模块”增强
- 更新后的更优质量基线

## 任务拆解

### 任务一：脚本扩面复用

目标：继续复用 `fix-missing-h1`，把试点方法扩展到更多可控模块。

子任务：

- 增加 `docs:fix-h1:04`
- 增加 `docs:fix-h1:10`
- 在两个模块内批量补齐缺少一级标题文档

### 任务二：治理页模块清单增强

目标：让治理页不只是展示热点，还能展示本轮已治理模块和下一批推荐模块。

子任务：

- 新增“本轮已治理模块”卡片区
- 新增“下一批推荐模块”卡片区
- 保持热点排序与趋势视图继续有效

### 任务三：基线更新

目标：在多模块治理扩面后，把更优结果回写为新基线。

子任务：

- 重新计算最新质量报告
- 更新 `docs-quality-baseline.json`
- 确保 `docs:check` 基于新基线通过
