# 开发记录：VitePress 多模块标题治理扩面与修复清单增强

## 背景

M7 已经证明，缺少一级标题问题可以通过脚本安全地在单模块中批量落地修复。

M8 的重点，就是把这套能力扩面到更多模块，并让治理页开始具备“本轮完成了什么、下一轮该做什么”的任务感。

## 本轮改动

### 1. 标题治理继续扩面

继续复用 `fix-missing-h1`，把 `04非典型工具、类库等` 和 `10其他` 两个模块也纳入治理。

### 2. 新增模块级修复命令

为这两个模块新增：

- `npm run docs:fix-h1:04`
- `npm run docs:fix-h1:10`

### 3. 治理页开始具备修复清单表达

治理页新增：

- 本轮已治理模块
- 下一批推荐模块

这使得治理页不再只是“状态看板”，而更像“维护待办面板”。

### 4. 基线再次更新

在扩面修复和自测都通过后，把新的更优结果回写到基线文件中。
