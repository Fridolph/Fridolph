# 技术博客：VitePress 知识站如何在热点大模块里采用渐进治理策略

## 热点模块越大，越不能一口气全做完

当治理进入热点大模块时，最容易出现两种极端：

- 要么迟迟不敢动
- 要么一上来就全量改动，风险很高

更稳的方式往往是：先在大模块里选一个边界清晰的子目录试点。

## 为什么 `2024面试准备` 适合先做试点

它有几个特点：

- 目录边界清晰
- 文档数量可控
- 标题推导规则稳定
- 修复后收益明确

这类子目录非常适合用来验证“大模块渐进治理”策略。

## 累计治理清单为什么重要

如果治理页只显示当前热点，很容易忽略一个事实：很多问题其实已经在逐步被解决。

把累计治理清单放进站点治理页后，治理就开始从“问题清单”变成“修复历史 + 下一步建议”的组合。
