# 开发记录：VitePress 热点子目录治理扩展与推荐视图增强

## 背景

M9 已经验证了“热点大模块先挑一个子目录治理”的方式是可行的，但这还只是一轮试点。

M10 的重点，是把这种子目录治理节奏扩展到跨模块复用，并让治理页从模块级推荐继续细化到子目录级推荐。

## 本轮改动

### 1. 继续推进面试模块中的热点子目录治理

本轮对 `00面试相关整理/interviewMap的阅读笔记` 执行缺少一级标题修复，延续热点模块内渐进治理方式。

### 2. 把同一节奏复用到 Node.js 模块

本轮新增 `05Nodejs/Node入门2` 治理，验证标题治理脚本可以跨模块稳定复用。

### 3. 治理配置增加里程碑与展示标题

`remediationConfigs` 增加了 `title` 与 `milestone` 字段，使治理页可以区分累计治理与本轮治理。

### 4. 治理页增加下一批推荐子目录

治理页现在不仅有下一批推荐模块，还能把缺少一级标题最集中的子目录直接展示出来，方便后续持续拆小任务。
