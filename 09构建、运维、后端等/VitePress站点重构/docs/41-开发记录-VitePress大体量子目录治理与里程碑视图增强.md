# 开发记录：VitePress 大体量子目录治理与里程碑视图增强

## 背景

M10 已经证明子目录治理可以跨模块复制，但还没有覆盖更大体量的子目录，也没有把多轮治理的阶段信息清楚展示出来。

M11 的重点，是一边继续做更重一点的治理对象，一边把治理页开始做成真正的阶段化面板。

## 本轮改动

### 1. 治理 Vue 学习热点子目录

本轮对 `11Vue学习/vue2相关文档学习笔记` 执行缺少一级标题修复，把高频热点子目录纳入治理链路。

### 2. 继续推进面试模块的连续治理

本轮新增 `00面试相关整理/2019模拟面试及相关整理`，让同一个热点模块开始具备连续多轮子目录治理记录。

### 3. 治理页增加里程碑视图

治理页新增“治理里程碑视图”，开始按 M7、M8、M9、M10、M11 聚合展示治理范围和当前剩余问题。

### 4. 脚本入口与基线同步更新

本轮补充 `docs:fix-h1:vue2docs`、`docs:fix-h1:2019mock`，并在修复完成后回写新的质量基线。
