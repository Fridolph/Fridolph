# 开发记录：VitePress 标题治理扩面与热点子目录再推进

## 背景

M13 之后，资源问题已经收口，治理重点自然回到标题缺失。

M14 的目标，是继续沿用子目录级方式推进标题治理，并在热点列表中再拿下两块更有代表性的目录。

## 开发顺序

本轮按下面顺序推进：

1. 先确认当前推荐子目录中的热点范围。
2. 再为本轮对象补充脚本入口和治理配置。
3. 然后执行标题批量修复。
4. 接着生成新治理页并检查本轮范围结果。
5. 最后执行构建与巡检自测，并回写新基线。

在修复完成并通过自测后，把新的标题缺失结果回写为基线，为下一轮继续扩面提供新起点。
