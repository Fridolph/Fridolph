# M15 任务拆解：标题治理继续扩面与知识型目录推进

这份任务拆解文档用于承接 M15：在 M14 已继续推进热点子目录标题治理后，把治理范围进一步扩展到两类知识型目录。

## 本轮目标

让标题治理从“热点目录验证”继续走向“知识型目录沉淀”，同时回答两个问题：

- 在更偏知识索引型的目录里，批量补齐一级标题是否仍然稳定
- 多层目录结构下，治理节奏是否还能保持低成本复制

## 本轮交付范围

- `03JavaScript/JS API` 标题治理
- `09构建、运维、后端等/Java学习` 标题治理
- 新增脚本入口
- 新基线回写

## 业务流程梳理

本轮按下面顺序推进：

1. 先根据治理页推荐子目录与问题分布确认本轮对象。
2. 再补充对应脚本入口与治理配置。
3. 然后执行批量标题修复。
4. 修复完成后重新生成治理页，确认本轮范围中的标题缺失归零。
5. 最后执行构建与巡检自测，并回写新基线。

## 任务拆解

### 任务一：推进 JS API 子目录标题治理

目标：补齐 `03JavaScript/JS API` 中数组方法等知识卡片的一级标题，降低 JavaScript 模块中的标题缺失热点。

### 任务二：推进 Java 学习子目录标题治理

目标：补齐 `09构建、运维、后端等/Java学习` 中课程式知识文档的一级标题，验证更深层级目录仍可稳定治理。

### 任务三：补充脚本入口与治理配置

目标：把本轮对象接入现有治理配置和命令入口，确保治理页可以准确表达当前轮次。

### 任务四：基线更新

目标：在本轮修复结果稳定后，把新的标题缺失结果回写为基线，保证下一轮可以继续比较。
