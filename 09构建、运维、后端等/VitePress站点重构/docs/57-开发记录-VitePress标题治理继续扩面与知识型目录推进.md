# 开发记录：VitePress 标题治理继续扩面与知识型目录推进

## 背景

M14 之后，标题治理已经再次回到主线，并在热点子目录中继续下降。

M15 的重点，是继续选择两个更偏知识型、层级更深的目录，验证这套治理方式是否还能保持稳定复制。

## 开发顺序

本轮按下面顺序推进：

1. 先确认当前推荐子目录中的新热点范围。
2. 再补充对应脚本入口和治理配置。
3. 然后执行标题批量修复。
4. 接着生成新治理页并检查本轮范围结果。
5. 最后执行构建与巡检自测，并回写新基线。

## 本轮改动

### 1. 新增两条标题治理范围

本轮把下面两个子目录纳入 M15：

- `03JavaScript/JS API`
- `09构建、运维、后端等/Java学习`

### 2. 继续复用批量修复脚本

本轮依旧没有新增修复逻辑，而是继续复用 `fix-missing-h1`，验证它在知识卡片型目录和课程型目录里仍然稳定可用。

### 3. 新增脚本入口

为 M15 的两个对象补充独立命令入口，让本轮治理动作更容易回放、复核和继续使用。

### 4. 回写质量基线

在修复完成并通过自测后，把新的标题缺失结果写入基线，为后续里程碑继续扩面提供更准确的比较基准。
