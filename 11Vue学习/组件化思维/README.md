# Vue 组件化思维重构项目

这个目录已经从零散笔记，逐步整理成一个围绕 Vue 重构方法论展开的小型文档项目。

目前的内容不再只是单篇总结，而是形成了四层结构：

- 导航层：按问题和场景快速定位案例
- 方法层：总结通用重构框架
- 案例层：拆解具体页面与基础组件的重构方案
- 过程层：记录里程碑、详细设计和开发复盘
