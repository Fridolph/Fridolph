# 里程碑规划

这份里程碑规划文档，用来定义本轮 `11Vue学习/组件化思维` 文档化重构项目的执行顺序、交付物和当前状态。

## 项目目标

把零散的 Vue 练习项目重构经验，整理成一套具备下面特征的方法库：

- 有统一入口
- 有方法总纲
- 有案例拆解
- 有过程文档
- 有后续扩展位

## 当前推荐执行顺序

建议按下面顺序持续推进：

- 先阅读并遵循 [执行清单：里程碑任务开发与交付规范](./28-执行清单-里程碑任务开发与交付规范.md)
- 先维护导航层和统一框架
- 再增加新的案例文档
- 每次增加案例时同步补充开发记录
- 每个阶段结束后回看导航分类是否需要扩容

## 里程碑完成标准

判断一个里程碑是否真正完成，可以用下面的标准：

- 是否产出了明确文档文件
- 是否已经链接进入口页
- 是否可以被后续案例继续复用
- 是否降低了后续新增内容的组织成本
