## 拆解顺序

### 任务一：梳理页面编排复杂度中心

识别本轮真正的复杂度中心：

- 页面顶层应该直接消费几个稳定入口
- 页面业务 composable 和 feature 步骤 composable 应该怎样分层
- store 应该接哪些跨页面状态，哪些状态不该提升
- 页面级数据、SEO、埋点和 query 同步应该如何围绕同一份契约组织

### 任务二：形成详细设计

设计本轮案例将如何组织：

- 页面入口层与页面业务 composable 分层模型设计
- feature 步骤 composable 与 store 归属边界设计
- 页面契约驱动的数据获取与副作用协同设计
- 页面编排可复用性与语义保留设计
