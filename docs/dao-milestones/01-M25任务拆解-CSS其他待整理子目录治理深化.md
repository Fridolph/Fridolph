# M25任务拆解：CSS其他待整理子目录治理深化

这份文档用于定义 `M25` 的任务拆解。

## 本轮目标

围绕 `02CSS相关/其他待整理` 完成一轮按 Dao 流程推进的子目录治理闭环，继续压降全站缺少一级标题问题，并验证“杂项资料型 CSS 目录”也能稳定复用当前标题治理方案。

## 本轮范围

本轮范围包括：

- 锁定 `02CSS相关/其他待整理` 为当前治理对象
- 梳理资料汇总与命名规范两篇文档的标题命名差异
- 补充脚本入口并执行批量 H1 修复
- 对自动补齐结果做语义化收口，统一为 `CSS其他待整理：<主题>` 标题
- 完成自测、基线更新、开发记录和 Dao Commit 子任务提交准备

本轮不包含：

- 进入 `05Nodejs` 及其相关目录
- 并行处理 `02CSS相关` 其他已治理以外的目录
- 修改底层标题修复脚本逻辑

## 拆解顺序

### 任务一：目标与现状梳理

目标：确认为什么在 `M24` 之后切换到 `02CSS相关/其他待整理`。

完成标准：

- 已确认该目录当前缺少一级标题数量与治理收益
- 已识别杂项资料标题缺少模块上下文的风险
- 已说明为何本轮继续避开 `05Nodejs`

### 任务二：业务流程梳理

目标：让本轮主流程、异常回修和文档回写顺序提前对齐。

完成标准：

- 已明确“巡检 -> 批量修复 -> 语义收口 -> 自测 -> 记录”的主流程
- 已明确杂项资料型目录在自动补标题后仍需二次语义化收口的处理策略
- 已明确沉淀文档位置和更新顺序

### 任务三：详细设计

目标：明确 CSS 其他待整理目录的命名规范和收口边界。

完成标准：

- 已形成独立详细设计文档
- 已明确脚本入口和标题命名策略
- 已明确基线更新方式

### 任务四：开发实现

目标：完成当前 CSS 其他待整理子目录的标题治理，并确保指标继续下降。

完成标准：

- 目标目录缺少一级标题文档已补齐 H1
- 弱语义标题已统一改为 `CSS其他待整理：<主题>` 或等价上下文标题
- `docs:sync` 与 `docs:check` 最终通过

### 任务五：自测与记录

目标：把本轮过程、设计判断、结果和经验完整沉淀到里程碑文档中。

完成标准：

- 开发记录已更新
- 里程碑开发笔记已更新
- 当前轮次已完成 Dao Commit 子任务提交准备

## 本轮完成标准

- `02CSS相关/其他待整理` 完成一轮子目录治理
- 当前质量基线得到更新或确认
- 里程碑文档组已形成完整闭环
- 当前子任务已具备按 Dao Commit 方式提交的条件
