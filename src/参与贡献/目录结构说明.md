# 目录结构说明

本站按两个维度组织内容：**按技术领域寻找知识，按学习方式整理文章。** 新增内容前，请先查找已有主题，避免重复；涉及结构性调整时，先通过 Issue 说明目的。

## 技术领域

首页与侧边栏分为五类：

- **前端开发**：HTML/CSS、JavaScript、TypeScript、Vue、React、工程化等。
- **后端开发**：Node.js、NestJS、数据库与 PostgreSQL 等。
- **AI 应用开发**：大模型、Prompt、RAG、Agent 等。
- **通用基础**：算法、HTTP、浏览器、Web 安全、设计模式等。
- **性能优化**：前端、后端、数据库与 AI 应用的测量、定位和改进。

分类入口由 `src/.vitepress/data/learning.ts` 维护，侧边栏领域归类由 `src/.vitepress/config/sidebar/groupSidebar.js` 维护。已有技术目录编号继续保留，编号不决定导航顺序。

## 三种学习方式

### 概念与原理

文章位于 `src/概念与原理/`，使用 `s_` 前缀。说明是什么、解决什么问题、机制是什么，以及适用边界。可以链接对应的实践和自测。

### 编码与实践

文章位于 `src/编码与实践/`，使用 `c_` 前缀。说明问题、实现思路、运行方式与观察结果。外部 demo 可以放在独立仓库，文章应链接具体文件或提交。

复杂示例可使用 `::: details` 或 `::: code-group` 渐进展示。练习不只有一种答案，比较方案时请说明约束和取舍。

### 学习自测

文章位于 `src/学习自测/`，使用 `q_` 前缀。通过问题、参考回答与追问检查理解，既能用于日常回顾，也能用于面试复习。

先检查是否有重复问题；回答尽量简洁，涉及版本差异或容易误解的结论时补充边界。

## 文件命名

技术目录映射定义在 `src/.vitepress/config/sidebar/usePath.js` 的 `typeMap` 中，例如 `18nestjs`、`19database`。

```text
src/概念与原理/02js/s_js_1-base.md
src/学习自测/18nestjs/q_nestjs_5-basics.md
src/编码与实践/02js/c_js_2-deepcopy/c_js_2-deepcopy.md
```

`index` 编号用于区分文章，不决定展示顺序。创建文章后，在对应 sidebar 文件中通过 `useConceptItem`、`useSelfTestItem` 或 `usePracticeItem` 注册入口，并按需更新主题的 `intro.md`。

## 路线、资源与历史资料

- [学习路线](/学习路线/index)连接知识笔记、练习项目、博客和复盘，可使用[实践记录模板](/学习路线/实践记录模板)记录进展。
- [性能优化](/性能优化/index)是跨领域专题入口，缺少的实践逐步补齐。
- [学习资源](/学习资源/index)收录外部项目、博客及早期资料入口。
- `网友面经`、`相关准备`保留历史语境，通过资源页访问。

旧的三个核心栏目已经迁移；新增链接请使用新目录。旧 URL 的兼容跳转由构建脚本生成，无需复制旧文章。

## 提交前验证

必须使用 pnpm。运行 `pnpm check` 和 `pnpm build`，确认无类型错误和死链；修改导航或页面布局时，验证桌面与移动端。引用他人内容需注明来源，AI 整理的技术内容需人工审核。
