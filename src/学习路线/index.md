# 从知识到实践的学习路线

> 当前主线：在已有前端经验上，学习 NestJS、PostgreSQL 与 AI Agent 开发。本站建立知识索引，项目验证想法，博客记录理解与反思。

## 先选一个真实的小问题

练习是否有价值，不只看它是不是“大项目”。更值得展示的是：**要解决什么问题、为什么这样设计、如何验证、发现了哪些限制。**

建议先围绕一个持续演进的“学习笔记”功能练习：读取笔记 → 创建与修改 → 持久化 → 并发与异常 → 检索 → AI 辅助。每次只补一段可以验证的能力。

下面是学习建议，不代表这些业务功能已经实现。

跟课时，可以先读[编程范式](/概念与原理/16patterns/s_pn_24-programming_paradigms)、[DTO / DAO 与分层](/概念与原理/18nestjs/s_nestjs_11-layering_dto_dao)，再按[从需求到接口的最小闭环](/编码与实践/18nestjs/c_nestjs_1-service_design/c_nestjs_1-service_design)拆解练习；该方案目前处于设计阶段。

## 一个知识点怎样形成完整记录？

以“并发保存笔记”为例，可以逐步串起：

1. **原理**：理解事务、隔离级别和版本条件更新。
2. **实践**：在练习项目中模拟两个客户端同时保存。
3. **验证**：说明期待的行为，记录冲突响应和数据库结果。
4. **自测**：能否解释为什么事务本身不一定解决覆盖问题？
5. **复盘**：比较方案、记录失败场景，再链接对应博客文章。

记录里放具体文件、提交或 PR、运行方法与观察结果，比单纯列一个技术名词更有说服力。
