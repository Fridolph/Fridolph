# 概念与原理

> 建立 Web 开发的知识底座：不仅知道名词，也理解背景、机制和适用边界。

## 怎么学习一个概念？

1. **是什么**：用自己的话说明定义。
2. **为什么**：它解决什么具体问题？
3. **怎么工作**：用流程、示例或代码解释机制。
4. **边界在哪**：有哪些限制、代价和替代方案？
5. **如何验证**：设计一个小实验，再回到[学习自测](/学习自测/index)检查理解。

## 按方向浏览

- **前端开发**：HTML/CSS、JavaScript、TypeScript、Vue、React 与前端工程化。
- **后端开发**：Node.js、NestJS、数据库与[开发部署](/概念与原理/20deploy/intro)。
- **AI 应用开发**：大模型、Prompt、RAG、Agent 与工具调用。
- **通用基础**：网络、浏览器、安全、数据结构与设计模式。
- **性能优化**：[跨领域专题](/性能优化/index)。

通过侧边栏进入对应主题，或从[学习路线](/学习路线/index)串联阅读与实践。
