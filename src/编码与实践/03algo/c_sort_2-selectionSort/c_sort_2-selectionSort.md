# 选择排序 Selection Sort

每轮从未排序区域选最小值，再与该区域开头交换。它与冒泡排序的“连续交换相邻逆序项”不同；此前文章混用了冒泡步骤，这里与实现统一。

## JavaScript 代码实现

<<< ./selectionSort.js

```js
selectionSort([3, 1, 2, 1]) // [1, 1, 2, 3]，原地修改
```

## 复杂度与边界

比较次数不因已有序而明显减少，时间 O(n²)，额外空间 O(1)，交换次数 O(n)。基本实现不稳定：把最小值与头部元素交换，可能使相等值跨过彼此。若排序对象，需要重新约定比较器和稳定性，本例只处理有限数值。

修正了旧实现读取外部 `arr.length` 的问题，函数只依赖传入的 array；最小值就是当前位置时不做多余交换。
