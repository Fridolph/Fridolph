## 运行本轮整理的算法测试

在仓库根目录执行（不依赖第三方包）：

```bash
node --test src/编码与实践/03algo/__tests__/learning-algorithms.test.mjs
```

覆盖查找边界、随机范围、三元素洗牌路径、文本约定、大整数和基础排序。测试引用文章展示的同一份源码，后续修改算法也应重新运行。
