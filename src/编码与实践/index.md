# 编码与实践

> 把概念变成能运行、能观察、能解释的代码。这里保留手写练习与页面示例，也逐步关联完整业务功能的实践。

## 一次实践至少回答什么？

- 它解决什么问题，输入和预期输出是什么？
- 怎样运行，怎样复现结果？
- 正常情况和边界情况分别怎样表现？
- 为什么这样实现，还有什么限制？

现有页面中的可交互示例用于观察机制；更完整的全栈练习以 [AI-Journey-land](https://github.com/Fridolph/AI-Journey-land) 为载体，通过具体目录、提交和运行说明建立联系。

## 从练习到记录

使用[实践记录模板](/学习路线/实践记录模板)，连接原理、自测、代码与博客复盘。可以从很小的功能开始，每一步都留下可验证的结果。

通过侧边栏浏览已有代码，或先阅读[当前学习路线](/学习路线/index)。
